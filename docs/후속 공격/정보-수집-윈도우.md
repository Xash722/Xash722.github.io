# 윈도우 정보 수집

리눅스와 마찬가지로 윈도우에서도 권한 상승을 위한 정보 수집을 진행해야 한다.

## 유저 정보 수집
<br>
<figure style="text-align:center;">
    <img src="{{ '/assets/images/후속공격/윈도우정보수집/3_userinfo.png' | relative_url }}" style="width:500px;">
    <figcaption>유저 정보 확인</figcaption>
</figure>

<figure style="text-align:center;">
    <img src="{{ '/assets/images/후속공격/윈도우정보수집/4_otherusersgroups.png' | relative_url }}" style="width:500px;">
    <figcaption>다른 유저 및 그룹 확인</figcaption>
</figure>
<br>

| whoami /priv | 현재 로그인된 사용자 계정이 가진 권한 출력 |
|:--------:|:-----------------------------------------------:|
| net user <유저명> | 특정 유저의 상세 정보 출력 |
| net users | 호스트 내에 있는 모든 사용자 계정 목록 출력 |
| net localgroup | 호스트 내에 있는 모든 로컬 그룹 목록 출력 |

| sc.exe query <서비스명> | 해당 서비스 상태 확인 |
| Get-Service -name <서비스명> | 특정 서비스의 상태 정보 출력 |
