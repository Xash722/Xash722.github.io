# 후속 공격
<br>
초기 침투 후 권한 상승, 정보 수집, 네트워크 피벗을 위해 진행하는 추가 공격


## 후속 공격 종류

- 추가 정보 수집
> 내부망 이동을 위한 필요한 계정 정보 수집
- 권한 상승
> 루트, 로컬 관리자로 권한 상승 후 시스템 장악 -> 계정 정보, 데이터, 서비스 탈취
- 네트워크 피벗
> 내부망 이동, 망 분리 접근

<br>

<br>

1. 호스트 A의 기본 유저 권한을 탈취한 공격자는 후속 공격을 진행하기 위해 더 높은 권한을 획득하려 한다.
2. 호스트 A의 로컬 관리자로 권한 상승에 성공한다.
3. 권한 상승에 성공한 공격자는 여러 후속 공격 시도 후 다음 호스트 B로 이동해 장악에 성공한다.
4. 호스트 B에서 정보 수집을 통해 호스트 C 서버 계정 정보를 획득하여 C 서버 장악에 성공한다.
5. 공격자는 호스트 C에서 호스트 D 서버에 대한 취약점을 찾아내 호스트 D 서버 장악에 성공한다.
