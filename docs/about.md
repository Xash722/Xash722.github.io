# About

## 소개

SOC(보안관제)/블루팀 신입을 목표로 하고 있습니다.

공격자의 관점에서 공격 기법을 직접 실습해 보고 그 과정에서 남는 흔적을 탐지하고 대응하는 방법을 공부하고 있습니다.

## 목표 직무

- SOC / 보안관제

## 공격 기법을 공부하는 이유

SOC / 보안관제는 공격을 탐지하고 대응하는 직무이기 때문에 공격이 실제로 어떻게 동작하고 어떤 흔적을 남기는지를 알아야 한다고 생각합니다.

그래서 Recon -> Exploitation -> Post-Exploitation으로 이어지는 공격 실습을 직접 수행하며 공부하고 있습니다. ([공격 이해]({% link docs/offensive/index.md %}))

## 기술 / 관심 분야

- 로그 분석 : Windows 이벤트 로그, Sysmon
- SIEM / 탐지 : Splunk, 탐지 룰 작성, MITRE ATT&CK 매핑
- 공격 : 취약점 진단(NFS, MySQL, 자동화 스크립트), 웹 공격(ffuf 퍼징, LFI, Command Injection, Webshell), 계정 공격(브루트포스, 해시 크래킹), 리버스/바인드 셸, 후속 공격(정보 수집, 셸 업그레이드)
