# BHPT - mod5handson

## 개요

## 모의해킹 수행 내용

- 기간 : 08/13/2025
- 호스트 이름 : mod5handson
- IP 주소 : 172.31.201.145, 172.31.135.134
- 목적 : 보안 취약점 진단 및 침투테스트

1. 정보 수집
2. 웹 서버 디렉토리 브루트포스 중 osCommerce v2.3.4 발견
3. 공개 익스플로잇으로 osCommerce 침투 성공 -> 도커
4. 도커 안 로컬호스트에서만 실행중이었던 mysql 백엔드 DB 확인
5. MySQL DB 내에서 webadmin 유저의 MD5 해시화된 비밀번호 확인
6. MD5 해시 크래킹 -> webadmin 유저의 평문 비밀번호 획득
7. webadmin 유저로 ssh 접속
8. 권한 상승 정보수집 중 SUID 비트설정된 '/usr/bin/env' 바이너리 확인. GTFOBins를 이용해 루트 권한 획득.

### osCommerce
- osCommerce 2.3.4
- 2014년 7월 출시 - 취약점 존재 가능성 매우 높음
- https://www.exploit-db.com/exploits/44374
    - RCE
    - /install 디렉토리가 존재할 시 사용자 인증 없이 'install_4.php' 파일을 불러와 설정 파일 생성 가능. 설정 파일 안에 PHP 코드 인젝션을 통해 RCE 가능 -> 설정 파일(config file)을 브라우저로 방문해 삽입된 PHP 코드 실행
